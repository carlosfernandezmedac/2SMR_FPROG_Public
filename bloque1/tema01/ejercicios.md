## Ejercicio 1 — Hola, SMR

Crea un programa `HolaSMR.java` que escriba por consola, en tres líneas separadas:
```
Hola, SMR
Segundo curso
Fundamentos de Programación
```

## Ejercicio 2 — Dibuja con texto

Usando solo `System.out.println`, haz que el programa dibuje en consola un rectángulo
como este, con asteriscos:
```
*****
*   *
*   *
*****
```

## Ejercicio 3 — Encuentra los errores

El siguiente código no compila. Cópialo en VS Code, identifica todos los errores y
corrígelos hasta que funcione:

```java
public Class miPrograma {

    public static void main(String[] args) {
        system.out.println("Probando el programa")
        System.out.println('Segunda línea');
    }
}
```

## Ejercicio 4 — Documenta tu proyecto

Retoma el ejercicio 1 (`HolaSMR.java`) y añade:
- Un comentario de una línea antes de la clase, explicando su propósito.
- Un comentario de varias líneas (`/* ... */`) dentro del `main`, explicando qué hace
  el programa.
